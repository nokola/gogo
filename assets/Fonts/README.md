# Fonts

`Roboto Regular.ttf`, `Roboto Light.ttf`, `Roboto Medium.ttf` and
`Roboto Bold.ttf` are Google's Roboto, unchanged. Copyright 2011 Google
Inc. Licensed under the Apache License, Version 2.0: see `LICENSE-APACHE`
at the top of this repository.

They are here for the tests of `crates/gogo-text` and for the example app.
gogo itself ships no font: a host hands `TextEngine::new` the bytes of its
own.
