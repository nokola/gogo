# G9013 — `ListItem` lives exactly one place

`ListItem` is a `List` row's root: the unit selection (`selected`), the
focus cursor and taps attach to. Outside that seat it means nothing — the
List machinery that flips its states isn't there — so gogo refuses it
instead of leaving a dead-looking box:

```gogo
Column {
    ListItem { Label text="x" }     // error: no List, no row
}
```

```gogo
Column {
    empty { }
    repeat t by $item {
        ListItem { Label text=$item }   // error: a plain repeat isn't a List's
    }
}
```

```gogo
List l {
    repeat t by $item {
        empty { ListItem { Label text="e" } }   // error: empty content isn't a row
        ListItem {
            ListItem { Label text=$item }        // error: a row can't hold a row
        }
    }
}
```

Fixes: selection wants `List name { empty { } repeat ... { ListItem { ... } } }`;
a plain drawn box anywhere else is `Panel`.
