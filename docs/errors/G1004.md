# G1004 — `autowrap_mode` with no width to wrap at (lint)

Wrap-text needs a width to wrap AT. Two spellings provably never give it
one, and each fails in its own visible way. Advisory: the build still
succeeds.

**Dead wrap** — every box from the label up to a free parent sizes to its
content. A hug axis measures wrap-text at its UNWRAPPED, full single-line
extent (one meaning for hug, D254), so the label always gets the width of
its whole text on one line: the `autowrap_mode` never fires, and long
text overflows the screen instead of folding.

```gogo
Panel halign=center, valign=top, width=hug, height=hug {
    Column {
        Label info text="One finger: pan; two fingers: scale, rotate",
            autowrap_mode=word_smart          // warning: never wraps —
    }                                         // the Panel hugs its content
}
```

**Sliver wrap** — an engine container grants a child its raw minimum and
NO size keyword was written to give the grant a meaning: a bare label on
a `Row`'s main axis. A wrap-label's raw minimum is about one character
wide, so the text renders one letter per line. (A child that DOES say
`width=hug` or `halign=` gets the D254 natural-width floor — it renders
single-line and warns as dead wrap instead.)

```gogo
Row {
    Label info text="a long sentence",
        autowrap_mode=word_smart              // warning: wraps at a sliver —
}                                             // the Row grants the minimum
```

Fixes, pick one:

- `max_width=fill` on the hugging box — size to the text, wrap only when
  the screen is narrower (the WPF text-block reading). A number caps at
  a fixed width instead.
- `width=fill` on the label — wrap at the space the parent gives.
- Drop `autowrap_mode` — single-line text needs no wrap.

A declared `min_width`/`min_size` floor on the box the container grants
also silences the sliver arm: the engine grants max(raw minimum, floor)
(D135), so the wrap binds at the floor — a real width, not a sliver. A
floor does NOT cure dead wrap: a hug axis still measures the text
unwrapped, and text wider than the floor still wins the grant.

The lint stands down where it can't reason: under `Scroll` (a scrolling
axis has its own doctrine, D138), aspect-derived axes, `Grid`/`Tiles`
cells, and the bare-hug code-owned opt-out (`width=hug, height=hug` with
nothing else positional — the code that owns the rect gives it a real
width the build can't see).
