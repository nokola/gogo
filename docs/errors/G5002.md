# G5002 — unknown style

A node wears `.SomeStyle`, but no style with that name is in scope.

## Where styles come from

- a top-level declaration in the same file: `style SomeStyle width=220 ...`
- an included file: `uses "styles/theme.gogo"` (its styles arrive with it)
- a widget's scoped styles, visible only inside that widget's body

## Common causes

- typo — the error suggests the closest declared name
- the `uses "..."` line for the file that declares it is missing
- the style is declared inside a widget and you're using it outside

## Fix

Declare it, include it, or take the suggestion.
