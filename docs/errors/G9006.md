# G9006 — repeat can't live inside a widget/control body (v1)

The same fence as G9005, same reason: **addressability**. A widget used
three times would give one repeat name three reconcilers — `set_items`
could not say which list it means.

```gogo
widget TaskPanel {
    Column {
        repeat tasks by $item.id { ... }   // error: TaskPanel x3 = "tasks" x3
    }
}
```

Do this instead — the repeat lives at the VIEW, the widget takes it as slot
content:

```gogo
widget TaskPanel {
    Panel padding=12 {
        slot
    }
}

View {
    TaskPanel {
        repeat tasks by $item.id {          // fill content is view-scope —
            TaskRow title=$item.title       // addressable, legal
        }
    }
}
```

The future form (designed, deferred) sources a widget-body repeat's
collection from a widget param instead of a name.
