# G9011 — a List row is one `ListItem` root

The row root is the UNIT: focus (the cursor) lands on it, the universal
`selected` flips on it, a tap is attributed to it, and the row's
`when held`/`when selected` looks live on it. Gogo never inserts an
implicit wrapper (hidden semantics), so the wrap is yours to write — and it
is `ListItem`, always: a bare `Label`/`Column` root would scatter those
duties across node types (and a focused `Label` draws the ENGINE's focus
frame over your styles — the D121 bug class this rule retired).

```gogo
List picker {
    empty { Label .Muted text="Nothing yet" }
    repeat tasks by $item.id {
        Label text=$item.title                  // error: not a ListItem
        Label .Muted text=$item.due             // error: two roots
    }
}
```

```gogo
List picker {
    empty { Label .Muted text="Nothing yet" }
    repeat tasks by $item.id {
        ListItem {                              // one root — the row
            Column {
                Label text=$item.title
                Label .Muted text=$item.due
            }
        }
    }
}
```

`ListItem` is a drawn box like `Panel` (`background=`/`padding=`), so the
selection look sits right on it: `ListItem .TaskLook { ... }` with
`style TaskLook { when selected background=accent }`.

Plain repeats outside a `List` stay unrestricted — the rule exists only
where selection needs the unit.
