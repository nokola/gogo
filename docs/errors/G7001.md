# G7001 — a buildable file needs exactly one root node

A file built as a view must contain exactly one widget tree. Directive
lines — `theme`, `style`, `anim`, `widget`, `uses`, `arrangement`,
top-level `when` / `transition`, `$name = value` — don't count; they
describe the tree, they aren't in it.

## Found more than one

Wrap the trees in a single container:

```gogo
Column root {
    Panel header { ... }
    Panel body   { ... }
}
```

## Found zero

Two possibilities:

- You meant to build a view — give it a root node.
- The file is a *fragment*: styles/theme values meant to be pulled in via
  `uses "..."` from other views. Fragments aren't built standalone — don't
  point the builder (or a lint that builds standalone) at them; every view
  that `uses` them checks them transitively.
