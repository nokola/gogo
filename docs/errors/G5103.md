# G5103 — live() and contract props

`live($prop)` is how a control's default tree shows a contract prop: the
binding re-resolves on every change (a drag, a key step, a code write).

```gogo
control Knob $value=0, $min=0, $max=1 {
    script "res://controls/knob.gd"
    Circle color=$surface2 {
        slot label { Label text=live($value) }   // updates as the knob turns
    }
}
```

This code covers the whole family:

- **bare `$prop` in a control's default tree** — error with the wrap fix-it.
  Contract props are runtime-mutable by nature; a pasted read would freeze
  at the initial value. (In a `widget`, `$x` is a static construction
  argument — bare reads are correct there. The spelling difference is the
  point.)
- **`live()` of a non-prop** — only contract props are live; theme values
  stay static bare refs (`color=$accent`).
- **`live()` outside a control's default tree** — fills and plain trees
  don't bind; move the read into the declaration.

## Notes

- `live()` targets engine properties (`text=`, `value=` ...). A binding is
  a WRITER: a `when` holding the same property is a two-writers error.
- There is no `bind()` — that hint routes here for WPF muscle memory.
