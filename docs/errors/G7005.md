# G7005 — a host-owned root axis needs a GogoPanelView host

`width=host` / `height=host` on a `Panel` root asks the root to ignore its
children on that axis. A raw `PanelContainer` host cannot: the engine's
PanelContainer computes its minimum in C++ and ignores a script's
`_get_minimum_size` (probed on Godot 4.7), so it counts every child on
every axis, and the declaration would be a silent no-op — the ratchet the
value exists to prevent would stay possible.

`GogoPanelView` (GDScript or C#) is a plain `Container` that plays
PanelContainer through gogo's own measure: the same styled box, padding
and borders, but the host-owned axes really are left to the host's code.

## Wrong

```csharp
public partial class AdStrip : PanelContainer { ... }   // hosting `Panel width=host`
```

```gdscript
extends PanelContainer
```

## Fix

```csharp
public partial class AdStrip : GogoPanelView { ... }
```

```gdscript
extends GogoPanelView
```

A `Panel` root WITHOUT host axes still builds on a raw `PanelContainer`
host (G7002) — only the host-owned axes need the gogo host.
