# G9010 — a List's body takes exactly one direct child `repeat`

A `List` IS selection over repeated items: its `selected` property, the
`selected` flips on its row roots and its focus cursor all attach to ONE
collection's items. Statics
mix freely around the repeat; a second repeat (or none) has no truthful
meaning.

```gogo
List picker select=many {
    Label .SectionHeader text="Today"          // statics: fine
    repeat tasks by $item.id {
        empty { Label .Muted text="Nothing due today" }
        TaskRow title=$item.title
    }
}
```

Zero repeats — you wanted a plain container:

```gogo
Column spacing=8 { Label a; Label b }          // no selection, no List
```

Two repeats — two selections, so two Lists (or move the plain repetition
into a `Column`):

```gogo
Column {
    List today   { repeat tasks    by $item.id { empty { } TaskRow ... } }
    List someday { repeat backlog  by $item.id { empty { } TaskRow ... } }
}
```
