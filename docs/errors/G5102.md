# G5102 — built-in state names are reserved

A `state` line declares a name from the built-in set (`hovered`,
`focused`, `focus_within`, `disabled`, `held`, `selected`). Built-in
states are runtime-maintained — declaring one is an OPT-IN, spelled
`state_builtin`:

```gogo
control Knob $value=0 {
    script "res://controls/knob.gd"
    state_builtin hovered, focused, disabled, held   // runtime-maintained; script may READ
    state clipping                                   // the behavior's own; script raises/lowers
}
```

The reservation holds under future growth of the built-in set: if a later
gogo adds a name your control already used as a custom state, the collision
is a loud error and a deliberate migration — never a silent
re-semanticization.

## Fix

Move the name to `state_builtin`, or rename your custom state.
