# G3001 — feel keys (`anim=` / `duration=` / `easing=`) on a `when` line

`when` declares what a state *looks* like — standing values, held while
the condition holds. How a change *feels* — its timing, easing, or a
choreographed anim — lives on `transition` lines. Putting a feel key on a
`when` mixes the two concepts.

## The split (one keyword per concept)

| keyword | concern | example |
|---|---|---|
| `when` | what the state looks like | `when held background=#FFFFFF, font_color=#000000` |
| `transition` | how flips between states feel | `transition any -> held duration=0.05` |
| `anim` | a transient flourish | `anim pop { self.scale to=1.05 }` |

## Wrong

```gogo
style MenuButton width=220, height=48 {
    when held background=#FFFFFFff, anim=test
}
```

## Fix

```gogo
style MenuButton width=220, height=48 {
    when held background=#FFFFFFff
    transition any -> held anim=test
}
```

A bare `transition duration=...` in the same block still covers every
other state change; the directional `any -> held` rule wins when
entering `held` (exact pair beats one-sided beats bare — see
REFERENCE.md "Transitions").

When the feel key was the `when` line's ONLY payload, the machine fix
rewrites the whole line into the transition — a rule's endpoint alone
subscribes the state (D182), so no standing response is needed:

```gogo
when held anim=test          // before
transition any -> held anim=test   // after
```
