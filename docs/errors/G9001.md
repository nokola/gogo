# G9001 — a repeat needs a unique name

The name is not decoration: it is the ADDRESS code hands the collection to.

```gogo
Column {
    repeat tasks by $item.id {
        TaskRow title=$item.title
    }
}
```

```gdscript
Gogo.set_items(view, "tasks", tasks)   # assignment is the change event
```

This code covers both name failures:

- **no name** — there is nothing for `set_items` to target; the repeat could
  never receive data.
- **duplicate name** — two repeats with one name would split the address.
  Names are unique per view, like node names. To show the same data twice,
  give each site its own name and assign the same items to both:

  ```gogo
  repeat toolbar_brushes as $brush by $brush.id { ... }
  repeat settings_brushes as $brush by $brush.id { ... }
  ```

  ```gdscript
  set_items("toolbar_brushes", brushes)
  set_items("settings_brushes", brushes)
  ```

## Notes

- Names inside the repeat's BODY are per-item local (the widget-body rule) —
  they never land in the view's named map, so item templates can't collide
  with view names.
