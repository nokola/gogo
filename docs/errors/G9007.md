# G9007 — the `empty` block: required, first, one, bare

`empty { ... }` is the repeat's base case — its children show iff the
collection has zero items (the initial state included, before any
assignment).

```gogo
repeat tasks by $item.id {
    empty {
        Label .Muted text="Nothing due today"
    }
    TaskRow title=$item.title
}
```

The rules this code enforces:

- **required** — every list answers the zero-items question VISIBLY, and
  the block appearing in every repeat is what keeps the feature
  discoverable. Genuinely nothing to show? A literal `empty { }` is legal
  and says exactly that: "considered — show nothing."
- **first in the body** — the base case is stated before the per-item case;
  first position puts the zero-items screen (the classic never-designed
  state) in front of every reader; and everything after it is per-item —
  one clean boundary.
- **exactly one** per repeat.
- **nothing on its line** — no name, props or styles; looks belong on its
  children.
- **only at the top of a repeat body** — an `empty` nested inside the item
  template has no zero-items to answer for.

## Notes

- `empty` replaces only the repeat's own expansion. Static siblings of the
  repeat (headers, footers) stay regardless of the collection's size.
- It is a block, not a `when`, because `when`s overlay properties and this
  swaps STRUCTURE.
