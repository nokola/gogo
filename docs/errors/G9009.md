# G9009 — a repeat line takes a name and clauses only

`repeat` is erased structure (like `choice`): there is no runtime node to
style or size, so props, styles, sizes and flags have nowhere to land.

```gogo
repeat tasks by $item.id { ... }              // the whole legal surface
repeat tasks as $task by $task.id { ... }     //   (+ the rename clause)
```

Where the rejected members belong instead:

- **looks and layout** (`spacing=`, styles, sizes) — on the PARENT container
  (`Column spacing=8 { repeat ... }`) or on the item template inside the
  block.
- **the collection** — from code: `Gogo.set_items(view, "tasks", items)`.
  There is no `items=` prop in v1 (it joins as an ordinary prop when a
  data-binding layer exists).
- **events** — selection/activation belong to the `List` control (its own
  round); plain repeats wire handlers on nodes INSIDE the template, which
  carry the item's key as their trailing argument.
