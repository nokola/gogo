# G9016 — a List's `empty` lives on the List body

The zero-items view is the LIST's presentation (D128): it shows beside the
statics (headers stay) while no items are present, and it may use the
List's whole box — free placement, art, a call-to-action. So it sits on
the List body, not inside the repeat, and it is REQUIRED there (the G9007
doctrine, one seat up): every list answers the zero-items question
visibly, and literally `empty { }` says "considered: show nothing".

```gogo
List picker {
    Label text="Today"
    empty { Layers { Label text="no tasks yet" } }
    repeat tasks by $item.id {
        ListItem { Label text=$item.title }
    }
}
```

Inside a List, a repeat carries NO `empty` block — one concept, one seat:

```gogo
List picker {
    repeat tasks by $item.id {
        empty { Label text="none" }     // error: move it up, beside the statics
        ListItem { Label text=$item.title }
    }
}
```

Plain repeats (outside a List) keep the G9007 form — `empty` first in the
repeat body.
