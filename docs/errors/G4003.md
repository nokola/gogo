# G4003 — two writers on one property

A `when` *holds* a motion word (a standing value like `scale=0.96`) while
a transition's `anim=` *drives* the same property on the same control.
Both are writers; on every state flip they would fight over the offset
transform and the loser flickers.

The error shows both places: the anim lane that drives the property
(primary caret) and the `when` that holds it (secondary underline). The
holding `when` may live on the NODE while the `anim=` sits on the STYLE the
node wears — the two-span error exists because one line alone looks like
a resolver bug.

## Wrong

```gogo
style MenuButton width=220, height=48 {
    when held background=#FFFFFFff
    transition any -> held anim=press   // drives self.scale on every wearer
}
anim press { self.scale to=0.9, duration=0.1 }

Button newGame .MenuButton text="New Game" {
    when held scale=0.96                 // ...and this HOLDS scale. Conflict.
}
```

## Fix — keep exactly one writer

Either drop the held value:

```gogo
Button newGame .MenuButton text="New Game" {
    when held background=#00ff00        // scale removed — anim press owns it
}
```

or drop the anim's lane and let the `when` hold it (whens tween with the
scope's `transition duration=`, so simple press-scale needs no anim at
all):

```gogo
style MenuButton width=220, height=48 {
    transition duration=0.08
    when held scale=0.9, background=#FFFFFFff
}
```
