# G9008 — dotted $refs exist only on repeat item bindings

`$x.field` reads a FIELD of the current repeat item. Theme values and
widget params are flat — a dot on any other `$ref` means nothing.

```gogo
repeat tasks as $task by $task.id {
    TaskRow title=$task.title       // field path: legal, reads the item
}

Label text=$task.title              // error: no repeat binding in scope
Label color=$accent.dark            // error: theme values are flat
```

## Notes

- Item bindings are STATIC values re-applied at each `set_items` assignment
  — assignment is the update event. No `live()` inside repeat; the
  bare-`$`-is-static doctrine holds.
- Inside a repeat, only the declared binding dots — `$other.field` with
  `$task` in scope is still this error (the caret names the in-scope
  binding).
