# G5105 — automatic slots must stay relayout-local

A slot with `automatic=length` or `automatic=position` sits in a host that
measures its children on the driven axis (a `Column`/`Row`/`Grid`/`Panel`
...). The driver writes the driven layout property every frame during a
drag; if that write fed parent measurement, every drag would thrash the
whole layout.

```gogo
control Fader $value=0, $min=0, $max=100 {
    script "res://controls/fader.gd"
    Column {
        slot track height=24 {
            // OK: a slot REGION is a free host
            slot thumb automatic=position by $value in $min..$max { Circle 12x12 }
        }
        // slot bad automatic=position by $value in $min..$max { ... }
        //   ^ error: Column measures children
    }
}
```

## Fix

Seat the automatic slot in a free-placement host: a named slot region (the
usual shape — track holds thumb and progress), `Layers`, or `Circle`. The
v1 built-in composites satisfy this by construction; the rule exists so a
user control can't declare a contract whose driver would thrash layout
(spec §4.5).
