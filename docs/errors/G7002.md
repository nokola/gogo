# G7002 — the host class must match the root kind

A .gogo file's root isn't created *under* the host — the host **is** the
root. Builds and hot reloads swap the root's children while the root itself
stays the same live instance (that's what keeps state, focus and the scene
tree stable across reloads). So the host's class must match what the file's
root kind needs:

- **`View` root (a screen)** → the host must extend `Control` and must NOT
  be a `Container`. Screen roots are free placement — a Container host would
  stomp every root child's anchors on its first sort. `GogoView` is the
  ready-made base.
- **`Panel` root (a component)** → the host must extend `GogoPanelView`
  (preferred — a Container that plays PanelContainer through gogo's own
  measure, so `width=host` axes work, D283) or `PanelContainer` (accepted,
  minus host axes — G7005). The root IS the styled box: the plate draws
  natively and padding/borders inset the content.

## Wrong

```csharp
public partial class Menu : PanelContainer { ... }   // hosting a View root
public partial class Toast : Control { ... }         // hosting a Panel root — plain Control has no container sort
```

## Fix

Pick the base that matches the file's first word:

```csharp
public partial class Menu : GogoView { ... }        // View root — a screen
public partial class Toast : GogoPanelView { ... }  // Panel root — a component
```

```gdscript
extends GogoView        # View root
extends GogoPanelView   # Panel root
```
