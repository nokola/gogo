# G2003 — a one-stop gradient renders as a solid

The `stops=` list has a single color:

```
Gradient veil stops=[blue]        // error[G2003] — one color, no fade
```

## Why this is an error

A gradient interpolates BETWEEN stops. With one stop there is nothing to
fade to — every pixel of the box paints the same color, which is exactly
what `Rectangle` does for a fraction of the cost (one ColorRect vs a
generated texture). Letting it build would hide a cheap solid behind an
expensive-looking word, and the reader six months later would hunt for a
fade that was never there.

Node types are honest about cost the way `&str`/`String` are in Rust: when
the character differs, the type differs.

## Fix

Machine-applicable (the editor offers Apply):

```
Rectangle veil color=blue
```

Or, if a fade was the intent, give the gradient something to fade to:

```
Gradient veil stops=[blue, blue/0]      // fade to transparent
Gradient veil stops=[blue@0, blue@0.94, blue/0@1]   // hold, then fade
```

The reverse also reads better than it looks: two stacked `Rectangle`s do NOT
make a fade — that is this error's cookbook cousin ("How do I fade a
color?", COOKBOOK.md).
