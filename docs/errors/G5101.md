# G5101 — a control needs a `script`

A `control` declaration has no `script` line. The script IS the boundary
between the two constructs: a control turns input into a value/state
machine (its behavior lives in the script); pure composition is a `widget`.

```gogo
control Knob $value=0, $min=0, $max=1 {
    script "res://controls/knob.gd"   // the behavior — mandatory
    ...
}
```

## The behavior file

Extends `GogoControlScript` and implements the hooks it needs
(`input_began`/`input_moved`/`input_ended`/`input_canceled`,
`key_action`, `accessibility_role`) — see the REFERENCE "Controls" section
and the reference implementation
`docs/design/examples/control_customization/knob.gd`.

## Fix

- add a `script "res://..."` line pointing at the behavior, or
- change `control` to `widget` if there is no behavior to write.
