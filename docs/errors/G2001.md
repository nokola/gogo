# G2001 — unknown property

The property isn't one of gogo's names for this control, isn't an engine
property of the underlying Control class, and isn't a registered custom
property.

## Why this is an error

gogo never applies a property it can't place — a silently ignored typo is
a bug you find weeks later on a phone screen. The error suggests the
closest known name (`did you mean ...?`) from this control's actual pool.

## Where the names come from

- gogo's own vocabulary: `width= height= background= font_color=
  font_size= halign= valign= margin= spacing= opacity= ...`
  (REFERENCE.md "Properties" is the full table).
- the control's engine properties, under their own snake_case names
  (`custom_minimum_size=`).
- custom properties registered at runtime via `Gogo.register_property()` —
  for the editor preview these must also be listed in
  `ProjectSettings: gogo/editor/custom_properties`, or the preview errors
  exactly like this.

## Fix

Take the suggestion, or look the concept up in REFERENCE.md — if you're
translating from another UI framework, the word you want may exist under
a different name (that case gets its own error, G2002).
