# G6001 — undefined $ref

A `$name` reference didn't resolve to anything in scope.

## Where $refs resolve from

In lookup order:

1. widget `$params` in scope (innermost widget first)
2. theme values: `$name = value` at the top level, or entries inside
   `theme { }` / `theme <variant> { }` blocks
3. values arriving via `uses "..."` includes

## Common causes

- typo — the error suggests the closest name, or lists what IS in scope
- the value is defined in another file that this file doesn't `uses`
- a widget param used outside its widget body
- a chain hop: `$a = $b` where `$b` doesn't exist — the caret can only
  point at the first hop; the missing name is the one in the message

## Fix

Define it (`$accent = #FF6347` at the top level is the cheapest), include
the file that has it, or take the suggestion.
