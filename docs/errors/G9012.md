# G9012 — select= picks a List's selection mode

Three modes, closed set (`one` is the default — the `choice` precedent:
one-of-N is the overwhelming case):

```gogo
List picker                { ... }   // select=one — `selected` is a key or null
List tags   select=many   { ... }   // `selected` is an Array of keys ([] = none)
List menu   select=off    { ... }   // activation/focus only — no selection (menus)
```

- `one` — tapping an item selects it; tapping the selected item again does
  NOT deselect (radio doctrine — `null` comes from code).
- `many` — tapping toggles the item's membership.
- `off` — gogo's shipped opt-out word (no `none` literal): items take focus
  and fire `On<Name>Activate`, nothing gets selected.

Double-tap or Enter fires `On<Name>Activate(key, item)` — the row's
trigger gesture (a single tap activates under `off`, where there is no
selection to move); `On<Name>Change(selected)` fires only when `selected`
actually changed.
