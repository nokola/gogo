# G3002 — that property moves by itself

A style, instance line or `when` assigns a property of an automatic slot
that the CONTROL drives from its value:

```
error[G3002]: slot.thumb.x moves by itself — Slider drives it from the value
```

A slot declared `automatic=position by $value in $min..$max` seats itself
at the value's fraction; `automatic=length by $value in $min..$max` sizes
itself; `automatic=presence by <state>` exists iff the state holds. Those
aspects have exactly ONE writer — the runtime driver —
so styles can never make a control's visuals disagree with its value (a
thumb drifting from its fill). That guarantee is the whole point of
automatic geometry (spec §4.3/§4.5).

## What you CAN style

Everything else about the slot: its look (`background`, `corner_radius`,
`border-*`), its size on the un-driven axis (a position thumb's `size=`),
and — as `when` responses — the motion vocabulary
(`when held slot.thumb.scale=1.2` uses the visual-only motion channel
and never touches the driven layout).

## Fix

Remove the assignment.
