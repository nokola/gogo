# G9014 — `when selected` inside a List row never fires (lint)

A `List` drives selection on the row ROOT — the `ListItem` — only. A
`when selected` worn by a node INSIDE the row (directly or through a
style) is a silent no-op: the node is never selected, so the look never
shows. This is advisory (a warning, the build still succeeds): dormant
universal styling is legal everywhere else, and here the intent is almost
always the row's selection look.

```gogo
List picker {
    empty { }
    repeat tasks by $item.id {
        ListItem {
            Label text=$item.title {
                when selected opacity=0.5   // warning: never fires here
            }
        }
    }
}
```

Fix: move the response (or the style that carries it) onto the row's
`ListItem`:

```gogo
List picker {
    empty { }
    repeat tasks by $item.id {
        ListItem {
            when selected opacity=0.5       // the List selects THIS node
            Label text=$item.title
        }
    }
}
```

A toggle-mode button inside the row (`Toggle`, `Radio`, `Check`, a
`toggle=true` Button) stays quiet — it drives its own `selected`,
independent of the List's selection.
