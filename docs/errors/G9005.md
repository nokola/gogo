# G9005 — repeats don't nest (v1)

One fence, one reason: **addressability**. `set_items` targets a repeat by
its view-scope name; a repeat inside another repeat's body would exist once
PER ITEM — one name, many reconcilers.

```gogo
repeat tasks by $item.id {
    Column {
        Label text=$item.title
        repeat subtasks by $item.id { ... }   // error: which item's subtasks?
    }
}
```

The future form (designed, deferred) sources the inner collection from the
outer item instead of a name — no address needed:

```gogo
repeat tasks as $task by $task.id {
    repeat $task.subtasks as $sub by $sub.id { ... }   // not in v1
}
```

Until then: derive a FLAT collection app-side (the data layer owns
transformations), or lift the inner list into its own view area.
