# G0002 — unclosed block: a `{` without its `}`

A block was opened but the file ended before its closing `}`. The caret
points at the `{` that was never closed — not at the end of the file,
because the missing brace belongs to whoever opened it.

## Why this is an error

Braces are gogo's only nesting. When one stays open, every line after it
silently becomes a child of the wrong node, so the parser stops rather
than guess where you meant the block to end.

## Wrong

```gogo
Column menu {
    Button a text="One"
    Button b text="Two"
// end of file — menu's { was never closed
```

## Fix

```gogo
Column menu {
    Button a text="One"
    Button b text="Two"
}
```

Indentation is your friend: the missing `}` almost always belongs at the
first line that dedents past the opener.
