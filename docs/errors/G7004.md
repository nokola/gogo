# G7004 — `width=host` / `height=host` is a root-only value

`host` in the sizing triad says: **the host's code owns this axis.** The
root's minimum ignores its children there (declared `min_width` /
`min_height` floors still count), and gogo writes no size flag and no
anchor for the axis — the box is whatever the code-behind sets, never
inflated by a child's transient measure.

Only the document root has a host. A node inside the tree has a parent in
the file, and the parent owns its box: `fill` takes the parent's space,
`hug` sizes to content, a number is exact.

## Wrong

```gogo
Panel card {
    Row strip width=host { ... }    // a Row's box comes from `card`
}
```

## Fix

```gogo
Panel card {
    Row strip width=fill { ... }
}
```

Or, when the box really is code-sized, move the declaration to the root:

```gogo
Panel strip width=host, height=host, min_width=320, min_height=50 {
    Row width=fill, height=fill { ... }
}
```

## Why it exists

Godot's `set_size` clamps to the combined minimum and bakes the clamped
value into the offsets; a later minimum drop never shrinks the box back.
A wrapping label measured at a stale width for one frame (a rotation
re-seats the host before its row has re-laid-out) inflated a code-sized
ad strip to the whole screen that way. `host` makes the root's minimum
deaf to that spike.
