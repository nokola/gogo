# G9004 — the item binding would shadow a $value in scope

`$item` (or your `as` name) must not collide with a theme value or a widget
param the template could also mean — silent shadowing would make one
spelling read two sources.

```gogo
$item = #FF6347FF          // a theme value named item...

Column {
    repeat rows as $row by $row.id {   // ...so the binding renames: `as`
        Label text=$row.title
    }
}
```

The rename clause IS the escape hatch — it's what makes the `$item` default
safe to standardize on.

## Notes

- The collision check runs at the repeat's declaration, not at first use —
  you find out before any data arrives.
