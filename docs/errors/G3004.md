# G3004 — alignment and `transition` cannot apply to the same arrangement

A `when <arrangement>` block re-anchors a node (`halign=` / `valign=`), but
a `transition` rule asks changes involving that arrangement to animate.
Both cannot hold: an anchor is one alignment or the other — "left" cannot
glide to "center", so there is nothing for the animation to show.

The rule underneath: alignment keys are legal in a `when` only when its
change is **instant** — screen whens always qualify, and an arrangement
`when` (plain, or composed with a screen class) qualifies exactly while no
`transition` rule can time that arrangement (no rule naming it, no bare
rule, no `any` endpoint).

The error shows both places — the alignment key (primary caret) and the
transition rule that times the arrangement (secondary underline).

## Wrong

```gogo
arrangement expanded
transition duration=0.2                 // a bare rule times EVERY arrangement...

when expanded {
    card.halign = center                // ...and this re-anchors. Conflict.
}
```

## Fix — keep exactly one of the two

Drop the transition rule (the arrangement then changes instantly, and the
alignment key is legal):

```gogo
arrangement expanded

when expanded {
    card.halign = center
}
```

or keep the animation and move the node with margins on its declared
anchor (margins can animate; an anchor cannot):

```gogo
arrangement expanded
transition duration=0.2

when expanded {
    card.margin_left = 100
}
```
