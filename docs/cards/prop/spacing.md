Uniform air between EVERY pair of a container's children (epx). The
one-off bigger break between groups is `gap`; air inside a box's own
edges is `padding`.

```
Column spacing=8 {
    Label first  text="one",   font_size=15
    Label second text="two",   font_size=15
    Label third  text="three", font_size=15
}
```
