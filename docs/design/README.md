# Design notes: history, not reference

These notes were written while the language was being designed, between
July and September 2026, when gogo still ran inside the Godot engine. They
record why a word exists and which other spellings were tried and dropped.

Their examples are NOT run through the compiler, and some use spellings
that have changed since. For what compiles today read
[../gogo-spec.md](../gogo-spec.md), [../REFERENCE.md](../REFERENCE.md) and
[../COOKBOOK.md](../COOKBOOK.md).
